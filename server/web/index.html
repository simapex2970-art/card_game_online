HOW TO PLAY

VEIL 53の遊び方

VEIL 53は、質問と推理を使って 相手の3枚のカードを見破る 2人用オンライン対戦カードゲームです。

01

3枚のカードが配られる

52枚の通常カードとJOKER1枚、 合計53枚の中から お互いに3枚ずつカードが配られます。

02

相手のカードについて質問する

自分のターンでは、 相手のまだ見つけていないカードについて 1つ質問できます。 答えはYESまたはNOで返されます。

03

質問からカードを絞り込む

偶数・奇数・絵札・ランク・数字の範囲・ スート・JOKERなどの質問を使って、 相手のカードを推理します。

04

相手のカードを1枚予想する

質問の答えをヒントに、 相手が持っていると思うカードを 1枚予想します。

05

正解したカードは発見済み

当てたカードは発見済みになります。 そのカードは、 以降の質問の判定対象から除外されます。

06

先に3枚すべて当てれば勝利

相手の3枚のカードを 先にすべて見破ったプレイヤーの勝利です。

MEMORY IS YOUR WEAPON.

質問履歴や発見済みカードの一覧は表示されません。 得られた情報を覚えながら推理することが、 VEIL 53の重要なポイントです。

JOKERにはスートや数字がありません。 JOKERについて調べる場合は、 JOKER専用の質問を使用します。
