RULE

HOW TO PLAY

VEIL 53の遊び方

相手の3枚のカードを、 質問と推理だけで見破るゲームです。

01

3枚のカード

53枚のカードから、 お互いに3枚ずつ配られます。 相手のカードを見ることはできません。

02

質問する

自分のターンでは、 相手の残っているカードについて 質問を1つ行います。

03

YES / NOから推理

偶数・奇数・絵札・ランク・ 数字・スート・JOKERなどを質問し、 相手のカードを絞り込みます。

04

1枚を予想

質問のあと、 相手が持っていると思うカードを 1枚予想します。

05

当てたカードは除外

一度正解したカードは、 以降の質問対象から除外されます。

06

3枚すべて当てれば勝利

相手の3枚を先にすべて見破った プレイヤーの勝利です。

MEMORY IS YOUR WEAPON.

質問履歴は表示されません。 過去の答えを覚えて推理してください。

ABOUT JOKER

JOKERは数字・偶数・奇数・絵札・ スートの質問には反応しません。 JOKER専用の質問で確認できます。
